# 🧩 Recover Video from IndexedDB Chunks

This method uses the **File System Access API** to export all chunks from IndexedDB, avoiding download limits.  
It will also generate a `chunks.txt` file ready for `ffmpeg`.

---

## Steps

1. Open your extension page → **Inspect** → **Console**.  
2. Paste and run the following script.  
   It injects a button into the page, so the file picker counts as a **user gesture**.


```js
(() => {
  const btn = document.createElement("button");
  btn.textContent = "Save all chunks to a folder";
  Object.assign(btn.style, {
    position: "fixed", top: "10px", right: "10px", zIndex: 999999,
    padding: "10px 14px", borderRadius: "8px", border: "1px solid #ccc",
    background: "#fff", cursor: "pointer", boxShadow: "0 2px 8px rgba(0,0,0,.15)"
  });
  document.body.appendChild(btn);

  btn.addEventListener("click", async () => {
    btn.disabled = true;
    try {
      const root = await window.showDirectoryPicker({ id: "screenity-chunks-export" });
      const sub = await root.getDirectoryHandle(
        `chunks_export_${new Date().toISOString().replace(/[:.]/g, "-")}`, { create: true }
      );

      const db = await new Promise((resolve, reject) => {
        const req = indexedDB.open("chunks", 2);
        req.onsuccess = () => resolve(req.result);
        req.onerror = () => reject(req.error);
      });
      const store = db.transaction("keyvaluepairs", "readonly").objectStore("keyvaluepairs");

      const items = [];
      await new Promise((resolve, reject) => {
        const cur = store.openCursor();
        cur.onsuccess = (e) => {
          const c = e.target.result;
          if (c) { const v = c.value; items.push({ index: v.index, blob: v.chunk }); c.continue(); }
          else resolve();
        };
        cur.onerror = reject;
      });
      items.sort((a, b) => a.index - b.index);

      let i = 0;
      for (const { index, blob } of items) {
        const name = `chunk_${String(index).padStart(5, "0")}.webm`;
        const fh = await sub.getFileHandle(name, { create: true });
        const w = await fh.createWritable();
        await w.write(blob);
        await w.close();
        if (++i % 100 === 0) console.log(`Saved ${i}/${items.length}...`);
      }

      const listTxt = items.map(({ index }) =>
        `file 'chunk_${String(index).padStart(5,"0")}.webm'`).join("\n");
      const listHandle = await sub.getFileHandle("chunks.txt", { create: true });
      const lw = await listHandle.createWritable();
      await lw.write(new Blob([listTxt], { type: "text/plain" }));
      await lw.close();

      console.log(`✅ Done. Saved ${items.length} files + chunks.txt in:`, sub);
      alert("Saved all chunks + chunks.txt. Now run ffmpeg in that folder.");
    } catch (e) {
      console.error(e);
      alert("Failed: " + (e && e.message ? e.message : e));
    } finally {
      btn.disabled = false;
    }
  });
})();
````

## 🛠️ Merging Chunks (Two Ways)

---

## First Way (Manual)

1. Open a terminal (**CMD/PowerShell on Windows**, **Terminal on Linux/Mac**) **inside the folder** where chunks are saved.
2. Join all chunks into one raw `.webm` file:

### Windows (CMD)

```bat
copy /b chunk_*.webm all.webm
````

### Linux/Mac

```bash
cat chunk_*.webm > all.webm
```

➡️ This creates **`all.webm`**.

---

## 🎬 Fixing the Container with FFmpeg

Some raw merges need fixing. Use **ffmpeg**:

```bash
ffmpeg -i all.webm -c copy fixed.webm
```

If the above fails (container issues), re-encode instead:

```bash
ffmpeg -i all.webm -c:v libvpx-vp9 -c:a libopus fixed.webm
```

✅ You now have a playable **`fixed.webm`** video.
